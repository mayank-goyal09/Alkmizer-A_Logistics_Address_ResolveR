# 📦 Logistics ResolveR — SaaS Product Website

Modern, high-converting, responsive SaaS landing page and live interactive demo for **Logistics ResolveR** (AI-Powered Address Structuring & Sequence Modeling).

---

## 🚀 Live Demo & Features

- **Live CRF Address Parser Sandbox**: Interactive client-side tokenizer simulating token-level sequence extraction (House Number, Street, Landmark, City, State, Pincode).
- **HUD Performance Metrics**: Live sequence latency (<8ms), confidence scoring (94-99%), and token counts.
- **Interactive ROI & Delivery Loss Calculator**: Dynamic computation of annual RTO savings and driver hours saved for 3PLs and carriers.
- **Modern Glassmorphism Theme**: Cyber dark palette with amber/orange accents and micro-interactions.
- **Bento Feature Grid**: Architecture breakdown explaining Linear-Chain CRF vs bulky LLMs.
- **Tiered SaaS Pricing Matrix**: Developer, Growth Fleet, and Enterprise plans with feature checklists.
- **FAQ Accordion & Clean Responsive Layout**: Optimized for mobile, tablet, and ultra-wide displays.

---

## 🛠️ GitHub Pages Deployment (Zero Build Steps)

This directory is 100% static (Vanilla HTML5, Modern CSS3, Modular JavaScript, and Lucide Icons via CDN) with **zero build step or compilation required**.

### How to Deploy on GitHub Pages:
1. Push this `website/` folder to your GitHub repository `mayank-goyal09/Logistics-Address-ResolveR`.
2. In GitHub, navigate to **Settings** → **Pages**.
3. Under **Branch**, select `main` and set folder to `/website` (or `/docs` / root).
4. Click **Save** — Your website will be live in under 60 seconds!

## 💻 Local Preview
To preview locally, open `index.html` directly in any web browser, or run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000/website/` in your browser.
